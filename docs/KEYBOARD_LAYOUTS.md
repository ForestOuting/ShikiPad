# 中文全拼与英文布局

适用版本：5.5.0–5.5.1，2026-10-23。5.5.1 沿用 5.5.0 的字母布局，另按用户要求调整三项时序默认值。完整键位见 [README](../README.md#打字键层)，路径见 [常用组合](COMMON_SEQUENCES.md)，可重算指标与约束见 [评估数据](LAYOUT_EVALUATION.json)。

## 优先级与固定条件

1. 每种语言全部 26 个字母都可移动，固定全部原数字、标点、Base 位置及操作规则。
2. 优先考虑字母频率与高频衔接，包括 ang/ing/ian 等片段；高频字母尽量放肩键。
3. 减少切层、同侧食指肩键/扳机移动、拇指反向及二者叠加；允许相邻方向同手连续输入，没有强制左右手交替。
4. 常用整词、全部完整拼音和计算机词汇用于检查取舍，**没有词级专属奖励**，也没有宏、自动补全或多字母输出。
5. 两页面仍为 Enter 翻页、Tab 切中英文键位、Esc 退出。默认中文；不切换 Windows 输入法。

## 全面检查了什么

| 方面 | 本轮处理 | 证据范围与限制 |
|---|---|---|
| 字母频率 | 每种语言 50,000 条加权词条；肩键使用率与 26 字母排序 | 词频不是个人频率，外部语料另列 |
| 常用组合 | 所有观测双字母/三字母进入成本；2–6 字母另外列路径 | 长片段没有整词额外权重 |
| 中文结构 | 全部 112 种音节内衔接，前 100 种跨音节衔接 | 合并去重 209 种免于切层＋十字反向 |
| 英文结构 | 前 100 种词内衔接硬保护，其余按频率计成本 | 罕见组合和某些技术词仍可反向切层 |
| 实际手指 | 区分左右拇指、相邻/反向、肩键/扳机；计三字母回返及整串上次位置 | 未校准本人动作时间；手指按压力、静态疲劳未量测 |
| 连按与重复 | 所有双字母，包含 aa/ll/nn 等；所有观察三字母 | 真实 mapper + 假输出，不是人手速度实验 |
| 长句边界 | 中文连续片段；英文原句显式插入 Base 空格；中文逐音节空格敏感性 | 中文逐音节空格只是对照，不假设实际逐字提交 |
| 技术词 | 167 条中文技术词串、537 条英文技术词串，等权统计 | 人工样本，不代表整个计算机领域频率；不用于选型 |
| 数字符号与编辑 | 原位逐一验证，64 输出身份完整，Base/修饰/重复测试 | 混合代码的标点、大小写、选词总耗时未完整建模 |
| 切层判定 | 5.5.1 的 30/35/40/45 ms 边界、后置宽限、同位置快速点按、晚组合撤回、语言快照 | 切层重叠是否顺手仍需手柄实测 |
| 语料与权重偏差 | 外部文本、技术样本、108 组相对权重、严格前16字母肩键对照 | 不把同源验证集或大量模拟当作独立人体实验 |

## 选择过程

先比较“训练频率前 16 字母全在肩键”的两组搜索，再让全部字母自由移动做两组搜索。两类均使用四种偏好（平衡、少切层、拇指、食指）；自由搜索分别使用 0.5、1.0 的扳机字母成本并采用不同种子，包含直接完整三字母目标搜索。原布局可作为起点，没有少改位置奖励。

所有可行候选汇总后，按统一成本、扩大后的保护条件选型。最终字母频率优先的扳机代理成本为 **1.0**（5.4.0 是 0.15）；这是依照使用偏好设置的相对权重，**不是测得的扳机耗时**。并检查 0.35/0.65/1.0/1.5 等权重与不同切层/拇指/食指代价的组合。整词奖励始终为 0。

相对切层成本 1.0，同侧食指移位附加 0.65；相邻拇指移动 0.38，十字反向 1.15，图案键反向 0.82，重复位置 0.12；切层同时反向附加 0.45。同拇指连续操作没有统一附加罚分。另计三字母回返、轻量拇指负担平衡、空格边界代理和上方位置成本。

独立 Python 重算了 796 条候选记录的评分与保护条件（含重复方案），并以另一套向量实现，对最终每种语言枚举全部 140,075 个两、三、四字母重排，未发现改进统一目标的邻居。它是所声明模型下的局部最优证据，不是 26! 全局最优证明。

在 108 组权重中，当前候选距对应可行候选池最低成本的最大差异：中文 0.46%、英文 0.48%。这是对已搜索候选的敏感性，不代表距数学全局最优或真实手速的误差。

### 高频字母放肩键的取舍

| 训练加权字母覆盖 | 5.4.0 | 5.5.0 | 只按频率前16理论最高 |
|---|---:|---:|---:|
| 中文 | 90.93% | 90.93% | 91.13% |
| 英文 | 88.81% | 89.74% | 89.82% |

两种语言前 10 高频字母都在肩键。严格让前 16 个全在肩键，并不自动得到最小整体动作负担：中文保留 c 在肩键以连接 ch，b 在扳机；英文把 c 移到肩键，保留 y 而把 g 放扳机。后者的频率覆盖距离前16上限仅约 0.09 个百分点，衔接收益由全部语料共同决定，未对 you 单词单独加权。

### 主要片段

- 中文 L1：`e x i l d a n g`。`ing` 为 □→×→○，右拇指两个相邻移动；`dan` 为 ←→↓→×；`ang/ian/eng/xian/liang` 同层。
- 中文 R1：`j y s c h o u z`。`zh/ch/sh/hu/ou/uo/you` 同层；`ong/shi` 仍需切一次，`ji/jian` 比 5.4.0 增加切层。
- 英文 R1：`r s a i n t e h`；L1：`m f d u c l y o`。`th/he/in/an/er/re/at` 同层，c 转到肩键；`ing` 仍切一次，`ion` 两次，`str` 仍有同层十字反向。
- 对比 5.4.0，中文改变 4 个字母位置，英文改变 5 个；全部 26 字母都参与过搜索，变化数量不是事先限制。

## 动作计数：改善和退步都保留

下表为每 100 字母的加权次数，箭头为 5.4.0→5.5.0。技术词为等权人工样本。

| 语言 / 数据 | 切层 | 同侧食指移位 | 切层＋十字反向 | 追踪拇指上次位置的反向 |
|---|---:|---:|---:|---:|
| 中文 / 训练 | 34.80→35.55 | 5.54→5.54 | 0.22→0.05 | 8.14→7.79 |
| 中文 / 外部 | 47.70→47.95 | 8.19→8.20 | 0.40→0.19 | 15.50→14.32 |
| 中文 / 技术词 | 39.82→41.19 | 6.81→6.81 | 0.32→0.08 | 10.10→10.74 |
| 英文 / 训练 | 38.03→38.24 | 4.20→4.41 | 0.38→0.39 | 11.27→11.25 |
| 英文 / 外部 | 34.72→34.97 | 3.84→4.09 | 0.32→0.31 | 10.63→10.40 |
| 英文 / 技术词 | 47.38→47.51 | 7.04→7.17 | 0.95→0.82 | 16.40→16.52 |

扩大保护范围后，中文训练成本比旧版更高；在 108 组未把硬约束计入成本的权重比较中，都不是更低成本。采用它是为了减少更多高频组合的反向切层，不是声称平均成本全面下降。外部中文反向切层约减 53%，但切层略增；中文技术词样本的总拇指反向还略增。

英文在 108 组权重中有 104 组加权成本低于旧版，但训练里的反向切层由 0.379 增为 0.391 次/百字母；外部与技术词样本则下降。不能称每项指标均改善。

对完整词、全部拼音音节及带空格句子的统计保存在评估数据。英文统一小写、提取 a–z 字母段并以空格分隔，标点和数字不计；空格按真实 Base × 作为独立动作处理，累计每只拇指与食指的位置，不把跨词字母直接当作相邻按键。中文对照连续片段与逐音节提交，不把一种输入法习惯当成通用规律。

任意字母串仍可能反向切层。例如中文跨音节 `oe/eq`，英文 `sc/wr` 没有全部消除；保护只保证明确列表中的有向双字母衔接。原位数字标点与字母、大小写修饰之间仍可能不顺，不在本次重新安排的范围内。

## 运行逻辑验证

连续输入回归通过 **13,788 组序列、41,891 个字母**。双语各 676 种双字母使用“先松后按”和“晚重叠 6 ms”两种层键过渡；覆盖中文 2,718 / 英文 7,047 种训练三字母、402 种中文拼音串，以及常用词和技术词。

这些测试调用真实 MapperForm 判定与 InputInjector 假输出：同层点按间隔 20 ms、切层点按间隔 60 ms、动作键按住 8 ms；逐一确认每个字母在自身 45 ms 判定截止时只输出一次、顺序正确、无遗留按下状态。20 ms 是模拟压力条件，不是人手速度承诺；测试没有打开 HID 或向系统注入按键。

5.5.1 按用户要求将组合窗口改为 35 ms、前置归属窗口改为 40 ms、本体累计截点改为 30 ms；修饰判定仍为 45 ms，本体追溯上限仍为 30 ms。边界回归覆盖恰好到达及刚刚超过这些窗口、晚形成组合撤销单层接管，以及新单层等待完整组合窗口后才输出的情况。预判层、动作语言快照、退出释放、触发阈值、释放宽限及全部 64 输出继续检查。布局研究指标仍对应 5.5.0 的键位；本次时序调整没有改变字母位置或键层判定算法。

## 仍需要本人实测的部分

- 长时间肩键保持、扳机压力、左右手力量差异、拇指尺寸与个人习惯，不能从文字语料可靠推算。
- 输入法候选选择、纠错率、大小写和代码符号的完整编辑耗时尚未测量。现有功能已核对，但没有给这些动作编造速度收益。
- 十字相邻操作仍需松开再按；滑过斜向时设备可能同时报告两方向。不能把相邻方向当作无需释放的免费滑动。
- 技术样本不覆盖个人所有领域；中文多音字由语料转换决定，可能出现读音偏差。没有唯一、对所有语料和所有人通用的最优键位。

## 数据与复现

训练为 wordfreq 3.1.1 各 50,000 条词项；中文用 pypinyin 0.55.0 + pypinyin-dict 0.9.0 CC-CEDICT 全拼转换。外部 ManyThings/Tatoeba 2026-02-13 句对包括 29,957 条中文连续片段、7,268 种计数英文词项，另检查 30,193 个去重英文原句的显式空格。版本号不代表文本采集年份；这些是通用频率，非个人键盘日志。

本轮外部/技术数据用于诊断，未向本轮搜索反馈；它们在前几轮已经看过，不能称完全未见过的最终留出集。原同源 train/validation 已合并训练，也不再作为独立验证。
